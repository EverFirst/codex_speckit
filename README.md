# TODO API

Single-user TODO REST API built with FastAPI, SQLite, and SQLAlchemy Core following the project constitution.

## Tech Stack

- Python 3.11+
- FastAPI 0.104+
- SQLAlchemy Core 2.x + SQLite 3
- Alembic for migrations
- Pydantic v2 for validation
- pytest + pytest-cov (≥70% coverage, TDD)
- Black + isort for formatting

## 1. Prerequisites

- Python 3.11
- pip (or uv/pipenv) and virtualenv support
- SQLite 3 (bundled with Python)
- Optional: `make`, `httpie`/`curl`

## 2. Setup

```bash
python -m venv .venv
. .venv/Scripts/activate    # Windows PowerShell
pip install --upgrade pip
pip install -e .[dev]
cp .env.example .env
```

Set environment variables (default):

```
DATABASE_URL=sqlite:///./todo.db
```

## 3. Database Migration

```bash
alembic upgrade head
```

Keeps schema consistent even for local dev/tests.

## 4. Run the API

```bash
uvicorn app.main:app --reload
```

Key endpoints:

- Swagger UI: http://127.0.0.1:8000/docs
- Health check: http://127.0.0.1:8000/health (hits DB via `SELECT 1`)
- Todos: `POST/GET /todos`, `GET/PUT/PATCH /todos/{id}`, `PATCH /todos/{id}/status`, `DELETE /todos/{id}`
- Structured logs print method/path/status/duration in ms.

## 5. Sample Workflow

```bash
# Create
http POST :8000/todos title="Read spec" description="finish clarify"
# List
http GET :8000/todos
# Toggle complete
http PATCH :8000/todos/<id>/status completed:=true
# Update
http PUT :8000/todos/<id> title="Read plan" description="update doc"
# Delete
http DELETE :8000/todos/<id>
```

Responses always include `id`, `created_at`, `updated_at`, and `completed_at`.

## 6. Testing & Coverage

```bash
pytest --cov=app --cov-report=term-missing
```

- Unit tests: `tests/unit`
- Integration tests: `tests/integration` (FastAPI TestClient + in-memory SQLite)
- Coverage threshold: ≥70% (constitution requirement)

## 7. Coding Standards

- Run `black .` and `isort .` before committing
- TDD workflow: write failing test → implement → refactor
- Keep Swagger docs in sync (auto-generated by FastAPI once routers/schemas updated)

## 8. Troubleshooting

- **SQLite locking**: stick to single uvicorn worker locally; integration tests already serialize via in-memory fixtures.
- **Missing migrations**: `alembic revision --autogenerate -m "message"` before `upgrade head`.
- **Slow responses (>200ms)**: ensure endpoints remain single-query operations; avoid unnecessary loops or sleeps.
